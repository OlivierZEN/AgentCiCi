# 产品销售排行口径

本模块把标准产品、订单和订单明细组织成确定性的当前销售事实，再独立聚合商机产品与合同作为前瞻信号。实际销售来自 `cloudccorderitem`，订单日期、状态和客户来自 `cloudccorder`，产品名称、编码和单位来自 `product`。`opportunitypdt` / `Opportunity` 的数量和金额绝不混入已实现销售。

- `SALES_QUANTITY`：有效订单明细的 `quantity` 合计。
- `SALES_AMOUNT`：有效订单明细的 `totalprice` 合计；缺失时使用数量乘单价。
- `ORDER_COUNT`：每个产品关联的有效订单去重数。
- `CUSTOMER_COUNT`：每个产品关联的有效订单客户去重数。
- 数量/金额贡献率：产品值除以 Top N 截断前的全量有效销售事实。
- 实现均价：正向订单销售额除以正向销量，避免负数退货扭曲。
- 客户集中度：最大客户与前三客户订单销售额占该产品销售额的比例。
- 产品管道：开放商机产品的数量、金额、商机数和最近预计签约日期。
- 合同信号：产品已实现销售关联的活跃合同、90 天内到期合同及续约商机缺口。

草稿、取消、作废、退回、关闭等状态不计入。负数退货扣减净销量与订单销售额。多币种且无可靠汇率时，金额主指标进入阻断；数量主指标可保留排行，但不合并金额、均价或基于金额的集中度。

时间缺失时默认最近 30 天；近 N 天、本月、上月、本季度和明确起止日期由确定性路由转换为 `startDate/endDate`。中文或阿拉伯数字 Top N 必须完整解析且只接受 1 到 20。多个不同指标、最少/最低/升序等非降序方向、不一致时间范围、无法可靠解析的显式时间以及越界或冲突的 Top N 均不得静默选择第一个值或回退到默认值。
