# CloudCC 按钮与链接能力说明

## 1. 什么是按钮与链接

按钮和链接用于将 CloudCC 数据与外部 URL、应用程序、公司内部网或其他后端办公系统集成。

按钮可显示在以下位置：

- 详细信息页：记录详情页操作按钮
- 相关列表：对象关联子列表区域操作按钮
- 列表视图：搜索/列表布局中的批量操作按钮

## 2. 按钮分类

### 2.1 标准按钮（Standard Button）

系统内置按钮，不可删除，可控制显示/隐藏。

| 标签 | 名称 | 显示类型 |
| --- | --- | --- |
| 提交待审批 | Submit | 详细信息页按钮 |
| 编辑 | Edit | 详细信息页按钮 |
| 新建 | New | 列表按钮 |
| 批量转移 | Batch Transfer | 列表按钮 |
| 删除 | Delete | 详细信息页按钮 |
| 批量新增 | Batch Added | 列表按钮 |
| 复制 | Clone | 详细信息页按钮 |
| 共享 | Share | 详细信息页按钮 |
| 批量删除 | Batch Delete | 列表按钮 |
| 批量编辑 | Batch Editor | 列表按钮 |
| 合并 | Merge | 列表按钮 |

### 2.2 自定义按钮（Custom Button）

开发者自定义按钮或链接，支持配置 URL 跳转、执行脚本、调用自定义类等行为。

## 3. 按钮显示类型（btnType）

| 值 | 说明 |
| --- | --- |
| `detailBtn` | 详细信息页按钮 |
| `listBtn` | 列表按钮 |

## 4. 按钮行为（event）

| 值 | 说明 |
| --- | --- |
| `URL` | 跳转到指定 URL |
| `JavaScript` | 执行 JavaScript 代码 |

## 5. 页面配置位置

- 详细信息页：在页面布局中配置按钮区域
- 相关列表：在页面布局的相关列表属性中配置
- 列表视图：在搜索布局中配置列表视图按钮
