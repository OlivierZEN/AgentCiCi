# FEAT-116 客户互动工作台标准渠道图标治理

## 1. 背景与问题

客户互动工作台的互动时间线当前把微信显示为通用消息气泡，并将 `CRM_TASK`、未知来源等多种记录统一回退为同一个消息图标。图标虽有颜色差异，但无法表达真实渠道和业务对象，且此前已修复的微信图标发生回归。

本次修复以“渠道品牌图标使用公开规范资产，通用业务图标使用成熟图标库”为唯一实现原则，不再手绘或拼接近似图形。

## 2. 用户与场景

- 用户：销售、客户经理、售前、销售主管。
- 场景：在紧凑时间线中快速区分微信沟通、电话、会议、邮件、CRM 任务、CRM 日程和客户反馈。
- 目标：用户不阅读来源文字也能初步判断记录类型，阅读文字后可获得准确来源说明。

## 3. 设计方向

- 视觉语气：克制、企业级、紧凑，不改变现有时间线轴线、密度和内容层级。
- 微信：使用公开维护的 Simple Icons 官方微信品牌路径与品牌绿色，不在项目中保存自绘 SVG 路径。
- 通用来源：继续使用项目既有的 Lucide 图标体系，按业务语义选用电话、日历、任务、邮件、反馈图标。
- 主题：八套主题保持相同图标、尺寸和位置；微信保留品牌识别色，其他来源颜色使用稳定语义色，不因主题切换改变含义。
- 交互：图标无悬浮位移、缩放或阴影，不引起时间线抖动。

## 4. 来源语义映射

| 原始来源 | 展示名称 | 图标来源 | 视觉语义 |
| --- | --- | --- | --- |
| `WECHAT` / 含“微信” | 微信 | Simple Icons `siWechat` | 微信品牌双气泡、品牌绿 |
| `PHONE` / 含“电话” | 通话录音 | Lucide `Phone` | 蓝色电话 |
| `MEETING` / 含“会议” | 会议纪要 | Lucide `CalendarDays` | 橙色日历 |
| `EMAIL` / 含“邮件” | 邮件 | Lucide `Mail` | 蓝紫色邮件 |
| `CRM_TASK` | CRM 任务 | Lucide `ClipboardCheck` | 主题金任务清单 |
| `CRM_EVENT` | CRM 日程 | Lucide `CalendarCheck2` | 橙色日程 |
| `CUSTOMER_FEEDBACK` / 含“反馈” | 客户反馈 | Lucide `MessageSquareText` | 青绿色反馈 |
| 其他 | 客户互动或原始来源名 | Lucide `MessageSquare` | 中性灰蓝兜底 |

映射必须基于稳定英文语义类名输出 CSS，例如 `is-social-chat`、`is-crm-task`，不得继续使用中文展示文案拼接样式类名，也不得把外部品牌名称扩散为项目自有标识符。

## 5. 实现设计

1. 在前端依赖中引入公开维护的 `simple-icons` 包，只读取其 `siWechat.path`、`siWechat.hex` 和标题元数据。
2. 新增轻量品牌图标渲染组件，统一使用 `24 × 24` viewBox、`currentColor` 和现有图标尺寸；组件自身不包含手绘 path。
3. 将来源识别、展示名称、语义类型和图标选择拆成可测试的纯函数。
4. `CRM_TASK` 和 `CRM_EVENT` 必须在通用关键字回退前精确匹配，避免再次误判。
5. 时间线样式继续使用 26/30 像素稳定圆形容器和现有轴线坐标，仅调整各来源的标准图标与语义色。

## 6. 异常与兼容

- 来源为空：展示“客户互动”，使用中性消息图标。
- 来源为后端新增值：保留原始来源文本，使用中性消息图标，页面不得报错。
- Simple Icons 依赖不可加载：构建阶段失败，禁止静默回退到自绘微信图标。
- 既有历史记录不做数据迁移，前端按 `sourceType` 即时映射。

## 7. 验收标准

1. 微信记录显示规范双气泡微信品牌图标，不再显示 Lucide `MessageCircle` 或自绘近似图形。
2. `CRM_TASK` 显示任务清单图标，`CRM_EVENT`/会议显示日历图标，电话和邮件使用对应标准图标。
3. 时间线垂直线连续，图标中心、日期列和内容列保持当前对齐，不产生横向位移或页面抖动。
4. 八套主题下图标形状、尺寸、轴线位置一致，微信品牌色可识别。
5. 来源映射单元测试、客户工作台测试、前端生产构建通过。
6. 在桌面端真实页面检查至少一条微信记录、一条 CRM 任务和一条会议/日程记录；控制台无新增错误，外层页面无新增溢出。

## 8. 非目标

- 不修改 CRM 数据结构、后端投影规则、身份同步或记录权限。
- 不重做时间线布局、客户列表或 AI 助手。
- 不新增移动端适配。
- 不将第三方品牌名称用于项目组件、CSS 类或业务标识符；依赖导出名仅作为第三方 API 使用。

## 9. 事实来源

- 产品与视觉：`PRODUCT.md`、`DESIGN.md`、`DESIGN.json`。
- 公开品牌图标：Simple Icons 官方项目与 npm 包，许可证为 CC0-1.0。
