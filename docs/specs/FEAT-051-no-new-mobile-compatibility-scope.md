# FEAT-051 不再默认增加移动端兼容实现与测试

## 背景

项目此前的页面质量流程默认要求桌面端与移动端截图、响应式检查和移动端无溢出验证。用户明确要求修正：功能设计、实现、测试过程中，不要再增加移动端兼容性实现和测试。

## 决策

- 常规功能设计、实现和测试默认只覆盖桌面端产品质量门。
- 不再默认新增移动端兼容实现、移动端断点、移动端专属布局、移动端截图或移动端自动化测试。
- 既有移动端代码和历史验证记录不批量回滚；本规则只约束后续新增工作。
- 只有用户明确单独提出移动端范围时，才把移动端兼容纳入规格、实现和验证。

## 落地范围

- `AGENTS.md`：新增项目级硬规则。
- `README.md`：同步 UI Design Governance 入口。
- `DESIGN.md`：页面质量流程改为桌面端截图与桌面端验收。
- `DESIGN.json`：结构化流程移除默认移动端截图和移动端响应式验收，新增 `featureScopeRules`。
- 活跃任务与相关规格：`TASK-114`、`TASK-115`、`TASK-116`、`TASK-124` 及 FEAT-037/038/046 已改为桌面端验证口径。

## 验收标准

- 顶层规范不再要求常规功能做移动端截图或移动端测试。
- 当前活跃任务不再把移动端兼容作为默认验收项。
- `DESIGN.json` 保持合法 JSON。
- `.claw` 状态校验通过。
