# FEAT-087 数据洞察仪表盘 UI 热修复

## 背景

生产版本 `2.3.4` 的“数据洞察”页面仍显示了一条来自旧 CRM 首页语境的顶部信息条，包括用户、组织、时间、币种和“销售云主页”。用户指出这条内容与新的数据洞察 AI 应用无关，必须去掉。

同时，仪表板下方的表格和风险客户卡片会被内容撑高，导致卡片在可视区域内向下飘出，破坏仪表盘墙的稳定布局。

## 目标

1. 删除数据洞察页面顶部旧系统信息条。
2. 数据洞察首屏只保留应用自身的分类 tab 和仪表盘卡片。
3. 固定仪表盘卡片在网格中的高度节奏，表格和列表内容在卡片内部约束，不允许撑破外层布局。
4. 发布新生产版本覆盖当前缺陷。

## 非目标

- 不改客户洞察应用结构。
- 不改后端数据口径。
- 不改 customer-workbench pagecomponent 配置。
- 不记录任何密码、token、cookie、secret 或可复用凭据。

## 验收标准

- `/app?aiApp=data-insight` 不再出现旧顶部信息条、组织名、币种或“销售云主页”。
- 数据洞察页面没有客户洞察项目/报告结构。
- 销售业绩、客户、商机、订单回款分类下卡片不越界，不出现横向页面溢出。
- 前端生产构建、桌面端浏览器截图检查和生产 smoke 通过。

## 交付记录

- 生产 `/ai/data-insights/dashboard` 对演示组织返回 `sourceMode=REAL_CRM_DEMO`，确认数据洞察仍使用独立的 CRM 聚合数据仪表板口径。
