# FEAT-132 - 发布修订版本号上限调整为365

## 目标

- 将生产版 `主.次.修订` 的修订段上限由 `12` 调整为 `365`。
- 例如 `2.8.365` 的下一个自动生产版本必须为 `2.9.1`。

## 范围

- 更新 `scripts/release-acr.sh` 的生产版本校验与递增逻辑。
- 更新生产发布手册中的规则与示例。
- 添加不依赖 ACR、Docker 或 Git 远端的脚本级回归测试，覆盖普通递增、365 进位、次版本进位和非法版本拒绝。

## 非目标

- 不变更主版本与次版本的现有上限 `12`。
- 不重写历史 Git tag、镜像 tag 或线上版本。
- 不执行生产发布。

## 验收标准

- `2.8.364` 递增为 `2.8.365`。
- `2.8.365` 递增为 `2.9.1`。
- `2.12.365` 递增为 `3.0.1`。
- `2.8.366` 被生产版本校验拒绝。
