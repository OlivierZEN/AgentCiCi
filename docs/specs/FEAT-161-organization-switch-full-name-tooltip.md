# FEAT-161 - 组织切换全称悬浮提示

## 目标

组织名称在侧栏中用首字符呈现，在切换菜单中因紧凑宽度可能显示省略号。用户将鼠标悬停在当前组织入口或任一组织名称上时，应能立即看到完整组织名称，避免误判当前组织或误切换。

## 设计与交互

- 认证后桌面工作台，保持鎏金账房及现有受控主题的颜色、密度、菜单尺寸和无填充文本菜单语汇。
- 当前组织入口的悬浮提示包含“当前组织：”和完整名称。
- 菜单中每个截断或未截断的组织名称均提供完整名称的原生提示，避免依赖视觉截断判断。
- 原生提示同时服务鼠标悬停与浏览器辅助技术语义；入口原有 `aria-label` 保留。

## 范围与边界

- 仅改前端组织入口与菜单名称元素的提示语义。
- 不改变组织名称来源、组织切换、管理后台入口、焦点行为、权限、API、主题或移动端布局。

## 验收标准

- 鼠标停留在左侧当前组织入口时可见完整当前组织名称。
- 鼠标停留在组织切换菜单任意名称时可见该组织全称，即使正文显示为省略号。
- 组织切换和“管理后台”按钮保持原有行为，前端测试与生产构建通过。

## 实施进展

- 已完成：当前组织入口使用“当前组织：完整名称”提示，菜单名称使用完整 `companyName` 提示。
- 已完成：已发布 `2.8.54 / 9a0fe88bf59f`，线上健康、版本、Nginx、HTTPS/HTTP 与新静态工件检查通过。真实组织菜单悬浮需由受权用户会话完成，发布会话未持有或伪造该凭据。
