# FEAT-122 - 智能体定时任务真实创建与链路事实纠偏

## 背景与目标

- 生产 Trace `df5e12f4` 中，用户明确要求创建定时获客任务，但系统只生成了任务参数 JSON；没有创建调度、没有执行网页搜索。
- 同一 Trace 把工作流代码解析结果标成 `published-executed`，并标记工具和知识已使用，实际字段却是 `tool_call_count=0`、`rag_context_count=0`。
- 本功能让用户在具备明确周期和任务内容时创建实际可由现有个人工作流调度器执行的任务；周期缺失时必须澄清，不得伪造创建成功。
- 链路必须把实际工具调用、检索和调度写入与“工作流定义检查”分开表达。

## 范围

### In Scope

- 提供受当前用户和当前智能体边界约束的内置“创建个人定时任务”工具，写入并发布到现有个人工作流及其真实触发器。
- 支持将已授权的 Tavily 搜索作为该个人工作流的实际执行工具，并在执行记录中保留脱敏结果摘要。
- 用户请求创建但未给出周期时，模型只请求补充周期，不生成代表“已创建”的参数 JSON。
- 工作流定义检查改名并改为只报告已解析的治理/能力边界；实际工具、RAG、技能和调度状态以真实运行数据为准。
- 常驻（always-on）技能计入 Trace 的已应用技能，避免已进入提示词却被展示为“未激活”。
- 组织管理员 Trace 详情沿用现有暖象牙、墨色、香槟金和紧凑密度，以明确文字区分“已执行”“未执行”“定义检查”。

### Out Of Scope

- 不创建外部 CRM 记录、不发送邮件、不扩大跨用户或跨组织权限。
- 不改已有个人工作流的调度频率、通知目标或历史触发器，除用户通过当前会话明确创建的新任务外。
- 不新增移动端适配；不把工作流代码字符串解析升级为通用沙箱执行器。

## 用户流程

1. 用户在 Web 会话中明确说“创建定时任务”，并提供任务主题与周期，例如“每天 09:00 搜索美国 K12 教育机构”。
2. 模型调用受限的创建工具，服务端只为当前用户和当前 Agent 追加一条个人 workflow routine、发布新版本并物化真实 trigger。
3. 工具返回 trigger、版本和下次执行时间；模型仅据此确认创建成功。
4. 调度器到期后执行已授权的网页搜索，并写入个人 workflow execution；Trace 记录真实工具调用与结果。
5. 若周期缺失，模型明确询问周期，不调用写工具，也不声称任务已经创建。

## 数据、权限与可观测性设计

- 复用 `user_workflow_*` 的版本、trigger、execution 与现有 30 秒调度器，不创建第二套定时任务表。
- 创建工具不接受模型任意指定的用户或 Agent；执行上下文由服务端传入，持久化范围固定为当前租户、当前用户、当前 Agent。
- 工具只在用户明确的创建请求且周期合法时调用；创建成功必须返回持久化 trigger id、routine key、版本和下次执行时间。周期缺失、无效或工具失败均不得返回成功。
- Trace 的 `tool_call_count`、RAG、已应用技能和调度结果来自真实调用记录。工作流代码只能标为“定义检查”，不得再写 `toolInvoked` 或 `knowledgeUsed` 等执行事实。
- 管理端不展示凭据、原始网页全文或未脱敏 payload；沿用 Trace 的管理员权限与脱敏上限。

## 验收标准

- 输入“创建定时任务：每天 09:00 搜索美国 K12 教育机构”会产生当前用户/Agent 的真实 workflow trigger，返回非空 routine key 和 nextFireAt。
- 输入相同任务但不含周期会要求补充周期，工具调用数为 0，且不存在新 trigger。
- 到期或 run-now 的 workflow 会实际调用已授权 Tavily 工具，execution 记录能显示真实成功/失败；未授权工具不会执行。
- Trace 不再把静态工作流解析呈现为工具或知识库已执行；实际调用数、技能和节点状态一致。
- 管理端以“工作流定义检查”呈现该阶段，并清楚显示是否真正执行工具、检索或调度；桌面端无横向溢出和 console error/warning。

## 风险与回滚

- 风险：模型可能错误构造周期或重复创建。通过周期校验、当前用户边界和任务幂等键降低风险；失败不创建 trigger。
- 风险：外部网页搜索失败。保留失败 execution，绝不写成功状态。
- 回滚：回退 backend/frontend 镜像即可停止新工具暴露；已创建的个人 trigger 可由现有用户 workflow 控制台停用，不删除历史执行审计。
