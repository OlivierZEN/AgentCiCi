# FEAT-075 - 智能体绑定知识库运行时检索触发修复

## 背景

2026-07-03 线上对话链路追踪显示：客户成功智能体已绑定“客户成功知识库”，用户提问 `CloudCC私有云部署注意事项有哪些`，但运行轨迹出现：

- `知识库检索未触发`
- `本轮输入未满足知识库检索条件`

代码排查结果：

- 前端在用户未手动选择知识库时会向 `/ai/chat/stream` 发送空 `knowledgeBaseIds`。
- 后端 `SkillResolverService.resolveKnowledgeBaseIds(...)` 已能把 Agent/Skill 默认绑定知识库解析为有效知识库范围。
- `ChatOrchestratorService.shouldUseKnowledgeRetrieval(...)` 对“未显式选择知识库”的场景还有一层关键词白名单；当前白名单缺少 `部署`、`私有云`、`注意事项`、`最佳实践` 等典型业务知识问法，导致已绑定知识库的业务智能体仍被跳过。

## 目标

- 已绑定知识库的业务智能体，在用户提出产品、部署、注意事项、方案、最佳实践等知识类问题时，应默认触发 RAG 检索。
- 保留问候、感谢、闲聊、才艺等低价值问题不触发检索，避免无意义消耗。
- 保留业务工具意图（如查邮件、查客户、查审批）默认不触发知识库检索，除非用户显式选择知识库或是企业微信客服会话。

## 范围

- 后端：调整 `ChatOrchestratorService.shouldUseKnowledgeRetrieval(...)` 的知识意图判定词表。
- 测试：补充 focused unit test 覆盖 Agent 默认知识库 + 部署/注意事项类问题。
- 文档：更新任务状态与测试报告。

## 非目标

- 不改变知识库绑定模型、租户隔离、Qdrant 查询过滤、知识库上传流程。
- 不改前端知识库手动选择器。
- 不让所有业务工具问题都自动检索知识库。

## 验收标准

- `CloudCC私有云部署注意事项有哪些` 在存在有效默认知识库且未显式选择知识库时返回 `shouldUseKnowledgeRetrieval=true`。
- `你好，上才艺` 等闲聊问题仍跳过知识库检索。
- `看下今天的潜在客户和订阅台账明细` 等业务工具查询在普通 Web 会话中仍跳过知识库检索。
- Focused 后端测试通过，生产发布后链路追踪应出现 `知识库检索` 或 `rag_done`，而不是 `知识库检索未触发`。
