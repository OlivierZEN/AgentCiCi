# FEAT-115 运营平台登录页宇宙智能视觉刷新

## 状态

- 状态：`in_progress`
- 任务：`TASK-209`
- 来源：用户确认的宇宙黑登录页 north-star 样例
- 范围：仅 `/platform/login` 桌面端登录页面视觉与语义结构

## 目标

平台运营人员进入 `/platform/login` 时，应感知这是一个具备智能体运行与治理能力的企业级控制入口。页面采用用户确认的宇宙黑、深空蓝、夜紫、星云青和星尘金视觉语言，通过左侧轨道智能核心、细分割线、右侧高留白登录表单和精细描边形成高级、可信、可识别的 Agent 平台入口。

本次只改页面呈现，不改变现有认证逻辑、接口、字段、token 存储、角色校验或登录后跳转。

## 用户与使用场景

- 用户：平台运营人员、平台治理与审计人员。
- 场景：桌面浏览器打开 `/platform/login`，在安静、专注的工作状态下完成平台账号登录。
- 成功标准：用户能在首屏快速识别平台身份、理解登录用途、完成邮箱/手机号与密码输入，并获得清楚的聚焦、禁用、登录中、成功或失败反馈。

## 视觉方向

### 色彩与材质

- `cosmic-black`：`#050607`，页面底色与大面积背景。
- `deep-space`：`#0e0f14`，右侧表单空间的深层表面。
- `dusk-blue`：`#0f1b2a`，左侧智能轨道场的冷色层。
- `nebula-teal`：`#0e1f22`，左侧极弱的智能场景色。
- `night-purple`：`#1a1c2a`，仅作为低对比背景层，不做渐变文字。
- `soft-white`：`#f5f6f8`，标题和主要文案。
- `stardust-gold`：`#f5d28a`，品牌微光、主操作边框和少量信号节点。
- `signal-teal`：`#8bcfc0`，运行状态点和少量辅助信号。

使用明确的深色表面层级、1px 细线和受控光晕表达材质；不使用玻璃拟态、卡片堆叠、霓虹泛光或大面积装饰性渐变。

### 构图

- 页面占满桌面首屏，左侧约 45%，右侧约 55%。
- 中央使用一条低对比度竖向分割线，不使用厚侧边强调线。
- 左侧只保留品牌标签、`AGENT OPERATIONS` 微标签、轨道智能核心和“运行状态 / 稳定”状态信息。
- 轨道智能核心使用可访问性隐藏的 SVG 装饰绘制，包含椭圆轨道、稀疏节点、中心信号点和少量青/金色节点。
- 右侧不放传统白色登录卡，使用独立的内容列和足够留白；表单宽度约 430px，垂直居中并略偏上。
- 输入框透明深色、低圆角、1px 描边；焦点状态使用高对比度星尘金/冷蓝外环。
- 主按钮为深色半透明实心、星尘金细边框和克制金色光晕，保持 `进入运营平台` 文案。

## 认证行为契约

以下行为必须保持不变：

1. `POST /auth/platform/password/login`。
2. 请求体继续发送 `identifier: identifier.trim()` 与 `password`。
3. 继续通过 `safeFetchJson` 处理返回结果，并要求 `success` 与 `data.token`。
4. 继续校验至少一个 `PLATFORM_` 角色。
5. 成功后继续写入 `LS_PLATFORM_TOKEN`，提示“登录成功。”并替换跳转到 `/platform`。
6. 空标识或空密码时主按钮继续禁用。

## 状态与交互

- 默认：表单可见，标识输入优先获得视觉注意但不自动抢占焦点。
- Hover：输入边框和按钮边框轻微提亮，轨道信号点保持克制。
- Focus-visible：输入和按钮提供不改变布局尺寸的 2px 外环。
- Disabled：标识或密码为空时按钮降低对比度，不显示光晕且禁止点击。
- Loading：沿用现有 `登录中…` notice，不新增第二套 loading 逻辑；按钮保持禁用状态。
- Error：沿用现有 `登录失败：...` 和无平台角色提示，使用星尘金偏暖的错误提示层，不改变文案或状态来源。
- Success：沿用现有“登录成功。”提示并跳转。
- Reduced motion：禁用轨道脉冲和入场动画，保留静态场景与焦点反馈。
