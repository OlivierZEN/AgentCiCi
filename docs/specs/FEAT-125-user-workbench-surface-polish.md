# FEAT-125 - 用户会话工作台浮层与操作面主题收敛

## 目标与范围

员工用户在 `/` 会话工作台中创建和使用快捷指令时，弹窗、快捷指令菜单、技能菜单、输入区工具按钮和会话历史选中行必须与当前受控主题保持一致。蓝色主题必须使用蓝灰表面、蓝色强调与蓝色遮罩，不能回退或混入鎏金账房色值；鎏金账房仅在用户实际选择该主题或离线回退时使用暖象牙、墨色和香槟金。其他六种受控主题同样通过既有 token 映射体现相同结构和语义。

本任务只收敛前端样式与可访问交互状态，不改变快捷指令、技能选择、会话创建、会话下载/删除、API、权限、数据结构或移动端布局。

## 反馈与根因

用户明确反馈当前已选择蓝色主题，但“添加快捷指令”弹窗仍显示鎏金账房暖色。输入区的快捷指令、技能和右侧当前会话选中行也呈现旧的独立控件语汇。

已确认根因是这些组件在 `frontend/src/assistant/cici-ui.css` 中使用了重复的硬编码色值、渐变、圆角与交互状态，而不是复用工作台的主题表面与语义 token。这是共享组件漂移，不是功能缺陷。

## 设计

- 场景：员工在长时间桌面会话中录入常用提示词、切换技能、回看上下文。界面应安静、紧凑、可预期，不能让浮层像另一套产品。
- 视觉方向：认证后 `product` register 的当前用户主题。所有颜色只从现有 `--theme-*` token 读取，禁止在这些组件中写死任何主题色；不使用渐变、玻璃拟态、浮夸阴影或新品牌装饰。
- 弹窗：不透明当前主题表面，统一标题区、正文区和页脚分隔，右上角关闭为无边框裸图标；输入控件有克制且可见的键盘焦点环；主要操作仅使用当前主题主色，取消操作为主题表面与结构线。
- 轻量菜单：快捷指令和技能菜单使用不透明主题表面、紧凑行高和浅结构线。行本身不做卡片化背景，hover/focus 仅用文字与结构线反馈；新增快捷指令保持单一主操作。
- 输入区与历史：上传、快捷指令、技能按钮复用一层紧凑控件语汇。会话历史默认使用文字层级和分隔，当前项以主题强调文字和直线结构反馈，不使用大面积填充或渐变；“新对话”遵循同一主操作语义。
- 状态：为菜单项、工具按钮、历史行、关闭按钮与表单控件覆盖 default、hover、focus-visible、active、disabled 和 saving 状态；遵守 `prefers-reduced-motion`，只保留不影响布局的短状态过渡。

## 验收标准

1. 蓝色主题下，快捷指令弹窗、快捷指令菜单、技能菜单、输入区工具和会话历史选中项不再出现鎏金账房的暖象牙、香槟金或金色遮罩。
2. 任一受控主题切换后，上述表面均随现有主题 token 变化，且文字、边框、主按钮与焦点态保持可读。
3. 快捷指令的新增、取消、保存中、空态、加载态、选择填入输入框等功能保持不变；技能和会话历史操作保持不变。
4. 通过键盘能看到关闭、输入、取消、提交、菜单项目与会话入口的焦点；禁用提交按钮和保存中状态清晰。
5. 桌面端真实浏览器检查快捷指令弹窗、两个菜单及会话历史，控制台无新增 error/warning，页面无外层横向溢出。

## 实施与验证

- 只修改 `AssistantApp.tsx` 必要的可访问语义和 `cici-ui.css` 的工作台相关样式；为关键渲染/交互补充或更新前端定向测试。
- 使用前端现有测试、生产构建和本地桌面浏览器的截图与交互检查验证。
- 不新增移动端断点或移动端验收。
