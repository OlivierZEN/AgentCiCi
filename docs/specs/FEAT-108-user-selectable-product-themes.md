# FEAT-108 - 用户级产品主题偏好

## 背景与目标

- AgentCiCi 同时以独立应用、管理端和 CloudCC CRM 嵌入页运行。用户希望在不同系统环境中选择更适合自己的视觉主题，并在再次登录、切换组织或从 CRM 进入时保持一致。
- 既有产品视觉事实源是“鎏金账房”。本功能不是创建八套不同页面，而是在同一布局、组件、密度和交互规范上切换语义化设计令牌，避免主题造成信息架构漂移。
- 每个账号拥有自己的主题偏好。主题切换应立即预览，保存后跨设备、跨组织和 CRM 嵌入入口同步；网络暂时不可用时仍保留本机最近选择。

## 主题目录

1. `gilded` / 鎏金账房：暖象牙画布、墨色文字、香槟金结构线，系统默认主题。
2. `crm-blue` / CRM 标准蓝：中性白蓝画布、CloudCC 风格标准蓝主色，优先用于 CRM 融合场景。
3. `ocean` / 蓝色海洋：晴空蓝与青蓝结构色，保持轻量、清晰和高对比。
4. `sakura` / 樱花粉语：低饱和樱花粉与莓红强调色，不使用大面积粉色填充。
5. `lavender` / 熏衣紫语：低饱和薰衣草表面与深紫强调色，不使用紫蓝渐变。
6. `avocado` / 牛油果小调：清浅绿灰画布、牛油果绿强调色，保留中性文字层级。
7. `wine` / 红酒醇香：浅灰玫瑰画布、酒红强调色，避免棕橙单色化。
8. `galaxy` / 星河幻境：深炭蓝画布、冷白文字与蓝紫强调色，是唯一深色主题；不用星点、光斑或装饰渐变。

## 范围

### In Scope

- 在个人设置增加“界面主题”页签，展示八个标准主题选项、色板、名称和简短语义说明。
- 选择主题后立即应用到当前页面；保存成功后写入当前账号服务端偏好。
- 登录前用本地缓存提前应用，登录后以服务端账号偏好为准并刷新本地缓存，减少页面闪烁。
- 普通组织用户的主题偏好存储在跨组织 `user_account`，确保同一身份切换组织时保持一致。
- 平台运营账号的主题偏好存储在 `platform_account`，确保平台端用户同样可持久化选择。
- AgentCiCi 主应用、个人设置、管理端、平台端和客户互动工作台共享同一主题基础设施；CloudCC 嵌入页使用当前 AgentCiCi 身份的主题。
- 建立语义化颜色令牌并覆盖主要壳层、面板、表单、按钮、Tab、对话框、客户互动工作台和状态表达。
- 增加后端迁移、API、单元测试、前端测试和桌面端八主题视觉检查。

### Out Of Scope

- 不允许用户自定义任意颜色、上传背景、调整字体或改变布局密度。
- 不为不同组织强制指定主题，不覆盖用户自主选择。
- 不改变页面信息架构、业务功能、CRM 数据权限或双向登录规则。
- 不新增移动端布局、移动端截图或移动端自动化测试。
- 不使用渐变、玻璃拟态、装饰光斑或主题专属位图背景。

## 用户场景

- 销售人员在 AgentCiCi 选择“CRM 标准蓝”，从 CloudCC CRM 打开客户互动工作台时继续看到相同主题，不影响 CRM 身份和客户数据权限。
- 用户选择“樱花粉语”后立即看到页面变化；刷新、重新登录或切换到另一个所属组织后仍保持选择。
- 平台运营人员选择“星河幻境”，平台管理页使用深色主题；退出后登录页只使用本地最近主题，重新认证后再与账号偏好对齐。
- 服务端保存暂时失败时，界面明确提示未同步，但本机预览和本地选择不丢失；下次成功读取账号偏好后恢复服务端事实源。

## 交互与视觉设计

- 入口位于个人设置的文本 Tab“界面主题”，不在顶栏增加新的常驻按钮。
- 主题列表采用两列紧凑选项；每项只有单一边界、三枚色块、名称、说明和标准单选状态，不使用卡片套卡片或装饰插画。
- 当前主题使用强调色文字、单选选中和一条明确结构线表达，不增加阴影、抬升或尺寸变化。
- 切换实时生效；保存过程显示轻量状态，失败时保留当前本地预览并允许重试。
- 八套主题必须保持相同的组件尺寸、文字级别、边框数量、Hover 几何和滚动规则。

## 数据与接口

### 数据字段

- `user_account.theme_code VARCHAR(32) NOT NULL DEFAULT 'gilded'`
- `platform_account.theme_code VARCHAR(32) NOT NULL DEFAULT 'gilded'`
- 服务端只接受上述八个稳定代码；未知值归一化为 `gilded`。

### 组织用户接口

- `GET /auth/me`：增加 `themeCode`。
- `PUT /auth/me/theme`：请求 `{ "themeCode": "crm-blue" }`，返回更新后的当前用户信息。

### 平台用户接口

- `GET /auth/platform/me`：增加 `themeCode`。
- `PUT /auth/platform/me/theme`：请求结构与组织用户一致。

### 前端同步规则

- 本地键保存最近成功选择，用于首屏预应用和离线回退，不作为登录后的权限或账号事实源。
- 当前用户接口成功后，服务端值覆盖本地值；用户主动选择后先本地应用，再调用对应主题接口。
- 同一浏览器页通过主题事件同步所有已挂载壳层，不需要整页刷新。

## 安全与兼容

- 主题 API 复用既有身份上下文，只能修改当前账号，不接受目标用户 ID。
- 主题代码使用服务端白名单，不接受 CSS、URL 或任意字符串，杜绝样式注入。
- 数据库默认值保证历史账号无迁移阻塞；前端未知主题也回退到 `gilded`。
- CloudCC token 与 AgentCiCi token 继续遵循既有双向身份规则；主题不参与认证、授权或 CRM MCP token 交换。

## 验收标准

- 个人设置可选择八套主题，当前选择和保存状态清晰；选择后无需刷新即可应用。
- 同一组织用户刷新、重新登录、切换组织及从 CloudCC CRM 嵌入进入后主题一致。
- 平台账号刷新与重新登录后主题一致。
- 八套主题在主应用、设置页、管理端和客户互动工作台主要区域均无未适配的关键白块、低对比文字、双层边框、布局抖动或滚动回归。
- 深色主题正文、表单、状态、按钮和焦点样式满足可读性；所有主题保持原有页面结构与控件尺寸。
- 无效主题 API 返回可理解的 4xx 错误，不写入数据库；历史或未知值安全回退。
- 后端聚焦测试、前端测试、生产构建、`git diff --check` 与真实桌面端八主题截图检查通过。

## 风险与回滚

- 风险：既有 CSS 硬编码颜色造成局部未换肤。通过语义令牌、主要产品壳层覆盖和八主题截图矩阵逐步收敛，不做一次性无关 CSS 重写。
- 风险：本地值与服务端值竞争导致闪烁。首屏先本地预应用，认证完成后只做一次服务端对齐。
- 风险：深色主题第三方或遗留组件对比不足。验收覆盖表单、对话框、列表、工作台和管理端关键路径。
- 回滚：前端移除主题入口并固定 `gilded`；数据库字段保留不影响旧版本，API 可向后兼容。
