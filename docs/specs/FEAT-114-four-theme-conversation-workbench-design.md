# FEAT-114 - 四套主题风格智能体对话工作台设计探索

## 1. 背景与目标

用户提供四张 UI 设计系统参考图，并确认以当前智能体对话工作台为例，制作四个新主题风格的桌面端展示效果图。本任务只做视觉探索和设计规格沉淀，目标是让团队可以在同一页面结构上比较四种风格的识别度、阅读负担和企业工作台适配性。

本任务不替换当前 `DESIGN.json` 的正式主题目录，不改变 AgentCiCi 现有页面结构、业务能力、接口或主题偏好机制。效果图是设计参考资产，后续如要落地，需另行审批并拆分实现任务。

## 2. 参考输入

- 参考图 A：Lightcore Prism，明亮、轻盈、棱镜光谱和高端极简。
- 参考图 B：Aerial Interface，航空控制、深色数据 HUD 和精准秩序。
- 参考图 C：Butterfly Iridescence，蝶翼自然纹理、蓝紫荧光和沉浸式曲线。
- 参考图 D：Cosmic Gravity，宇宙黑、星尘金、轨道线和安静的几何科技感。
- 页面基准图：当前 AgentCiCi 智能体对话工作台，包含左侧导航、智能体切换、中央会话、右侧工作概览、会话历史和底部输入区。

## 3. 共同页面骨架

四张效果图必须使用同一信息架构和同一业务内容，以便只比较视觉风格：

1. 左侧窄导航：组织入口、对话、联系人/客户、应用入口、设置和退出。
2. 顶部智能体选择：`思思（CiCi）` 与 `售后服务 Agent` 两个入口。
3. 中央对话区：用户问题、智能体回答、结论区、统计口径说明和数据表格。
4. 右侧上下文区：当前智能体状态、今日工作概览、会话历史与“新对话”。
5. 底部输入区：消息输入、附件、快捷指令、技能、语音和发送。
6. 展示比例：桌面端 16:10，目标画布约 1600 × 1000；不新增移动端方案。

## 4. 四套主题定义

### 4.1 棱镜晨光 / Prism Daylight

- **来源语汇**：参考图 A 的 Lightcore Prism。
- **物理场景**：上午的明亮办公桌旁，用户长时间阅读智能体结论，需要轻盈、清楚且不刺眼的工作台。
- **色彩**：乳白和雾灰作为大面积底色，墨色文字，少量香槟、薄荷、天蓝和珊瑚色构成“棱镜”强调。
- **材质与形态**：细边框、柔和圆角、轻微层次、宽松留白；允许在视觉素材和重点按钮中出现克制的光谱折射，但不把渐变作为生产主题 token 结论。
- **字体气质**：现代无衬线，标题轻量，数据与状态保持清晰中等字重。
- **对话表达**：回答面板接近纸张或半透明白纸的轻量层次，表格用淡色横线和清晰列标题区分。
- **记忆点**：右上或边缘出现一条极细的棱镜光带，作为视觉索引而不是装饰背景。

### 4.2 云端航迹 / Cloud Flight

- **来源语汇**：参考图 B 的 Aerial Interface。
- **物理场景**：夜间值守的 27 英寸显示器前，用户需要快速判断智能体状态、数据来源和下一步动作。
- **色彩**：深炭黑为画布，冷白为主文字，航空蓝和冰青作为数据强调；危险或等待状态使用少量琥珀色。
- **材质与形态**：直角或小圆角、极细分隔线、坐标/航线式辅助标记、稳定的网格节奏；避免把界面做成游戏化仪表盘。
- **字体气质**：正文使用高可读无衬线，时间、指标、状态码和表格数字采用等宽字体。
- **对话表达**：回答中的结论、数据截止时间、筛选条件和下一动作分成清晰的信息航段，右侧状态栏像飞行数据面板。
- **记忆点**：对话顶部有一条“飞行状态线”，将智能体状态与会话进度连接起来。

### 4.3 蝶翼流光 / Winged Iridescence

- **来源语汇**：参考图 C 的 Butterfly Iridescence。
- **物理场景**：傍晚的创意工作空间，用户在复杂业务信息之间切换，希望工具有生命力但不牺牲对话阅读。
- **色彩**：午夜蓝底，深海蓝表面，电光蓝、紫罗兰和青色作重点强调，极少量珠光白作为高亮。
- **材质与形态**：柔和大圆角、曲线切角、轻薄发光边缘；纹理只出现在智能体头像、空白区域或上下文插画，不覆盖正文区域。
- **字体气质**：圆润但不幼稚的无衬线，标题可有轻微艺术感，正文和数据仍然保持稳定中性。
- **对话表达**：智能体回答采用深色分层和轻量荧光焦点，关键结论用蓝紫色强调，不用大面积炫彩渐变文字。
- **记忆点**：智能体头像或右侧上下文区域使用一枚抽象蝶翼/流线纹理，强化主题识别。

### 4.4 引力余晖 / Gravity Afterglow

- **来源语汇**：参考图 D 的 Cosmic Gravity。
- **物理场景**：安静的深夜办公室，资深运营人员审阅复杂结论和证据链，界面需要克制、稳定、可信。
- **色彩**：宇宙黑和深蓝黑为主，柔白文字，星尘金作为主操作和关键轨道线，少量暮蓝和暗紫用于区分辅助状态。
- **材质与形态**：细线框、低对比结构线、几何圆环、精确间距；不使用大面积星点、流星、发光云团或营销式英雄画面。
- **字体气质**：几何无衬线，标题略带建筑感，正文保持中性；数据、时间和证据编号使用窄体或等宽辅助。
- **对话表达**：回答中的证据、口径和行动建议以“轨道节点”式层级组织，右侧工作概览用环形进度和线性指标表达。
- **记忆点**：输入区发送按钮、关键结论标记和状态线使用柔和金色，不做强烈霓虹发光。

## 5. 交互与状态要求

效果图至少展示以下状态：

- 当前选中的智能体。
- 用户消息与智能体回答。
- 统计结果暂无有效数据的结论语句。
- 右侧“等待确认 / 正在生成回复 / 本轮结果需要补充或确认”等状态。
- 新对话入口、会话历史选中项和输入区主操作。

四种主题都保持相同的控件几何、信息密度、阅读宽度和导航位置。主题差异只能来自颜色、字体、边框、材质、纹理和少量装饰索引；不得改变业务流程或组件树。

## 6. 设计治理约束

- 当前正式主题事实源仍是 `DESIGN.md`、`DESIGN.json` 和 FEAT-108。
- 本探索稿不新增正式主题代码、主题 token、主题偏好选项或移动端适配。
- 生产实现仍需遵循产品 register：清晰、克制、可信，优先服务对话阅读和企业任务流。
- 不使用参考项目或外部产品名作为实现层的组件、变量、路由、CSS 类或产物命名；本规格中仅保留其作为参考来源的说明。
- 所有后续生产实现都需要本地运行、真实浏览器桌面截图、交互状态检查和桌面端视觉 QA。

## 7. 交付物与验收

- 四张独立桌面端 PNG 效果图，分别对应四种主题名称。
- 本规格包含来源、物理场景、色彩策略、字体气质、材质、对话表达和限制条件。
- 四张图的页面骨架和业务内容可一一对照，主题差异清晰可辨。
- 图像不出现明显外部品牌标识、移动端布局、营销页 Hero 或与页面任务无关的装饰。
- 视觉检查关注：主题识别度、对话可读性、右侧上下文扫描速度、输入区可用性、状态对比度和桌面端布局稳定性。
