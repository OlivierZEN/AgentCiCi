# FEAT-127 - 本地遗留分支审查与主线整合

## 目标

- 审查四个尚未合并的本地分支：TASK-160、TASK-203、TASK-204、TASK-210。
- 以当前 `main` 的最新时间线为冲突事实源，保留未冲突且仍符合规格的功能、测试和文档。
- 合并前运行与改动相关的验证；过期、重复或与当前行为不兼容的旧变更不得回流主线。

## 范围与约束

- 仅处理上述四个分支及其与主线的合并冲突。
- `.claw` 热状态文件以当前 `main` 为准，不回填历史快照；任务历史保留在各自分支可追溯的提交中。
- 当前其他 worktree 的未提交工作不覆盖、不移动、不提交；发现其内容已被 `main` 吸收时，只报告并建议清理旧 worktree。
- 代码冲突优先保留主线较新的实现；只有经当前测试和规格证明仍缺失的修复才以兼容方式补入。

## 验收标准

1. 四个分支的提交均可从 `main` 到达。
2. 合并结果无未解决冲突、`git diff --check` 通过。
3. 新引入的测试与受影响的前端/后端验证通过，且不回退当前主线行为。
4. 当前 `main` 与 `origin/main` 的同步状态被如实记录；本地其他 worktree 的脏改动不被误删。
