# FEAT-158 - AgentCiCi AI表格菜单改为业务对象列表

## 背景与目标

当前 AgentCiCi 用户端左侧 AI表格菜单点击后进入外部 CRM 登录页，用户需要离开 AgentCiCi 才能查看租户业务数据。本次先交付桌面端高保真 UI 预览，明确“当前租户已开通的 Semattice 应用 → 业务对象 → 数据列表”的产品形态，为后续真实接口接入提供交互基线。

## 范围

### In Scope

- AI表格菜单点击后在 AgentCiCi 用户端内部展示 Semattice 业务对象列表。
- 展示当前租户已开通应用上下文、对象切换、对象记录数量和最近同步状态。
- 支持常用列表体验：关键词查询、对象筛选、刷新、选择行、自定义表头、分页、行详情抽屉预览。
- 使用当前 AgentCiCi 主题 token 和桌面端产品工作台规范，默认“鎏金账房”，并支持 CRM 标准蓝、蓝色海洋、樱花粉语、熏衣紫语、牛油果小调、红酒醇香、星河幻境等现有主题切换。
- 本阶段使用前端演示数据，交互行为可操作但不接入真实 Semattice API。

### Out Of Scope

- 不改动 Semattice API、鉴权、对象元数据或数据模型。
- 不在本阶段实现新增、编辑、删除、批量导入、真实导出和移动端适配。
- 不再打开 CloudCC 登录 iframe。

## 用户场景

- 企业成员点击左侧 AI表格菜单后，直接进入当前租户的“业务数据”列表。
- 用户从对象目录切换客户、商机、项目等对象，列表列和记录同步变化。
- 用户使用关键词快速查找记录，或打开表头设置隐藏不关注的字段。
- 用户点击一条记录，在右侧查看关键字段，不离开当前列表上下文。
- 没有匹配记录时，列表以清晰的空结果状态反馈，并允许一键清除查询。

## 现状与约束

- 当前实现位于 `frontend/src/assistant/AssistantApp.tsx`，AI表格分支原先渲染 `https://accounts.cloudcc.cn/#/login` iframe。
- AgentCiCi 认证后产品默认使用“鎏金账房”主题：暖象牙画布、墨色文字、香槟金结构线和紧凑企业工作台密度。
- 主题切换沿用已有 `data-theme` 和 `--theme-*` token，列表不创建独立色板或固定供应商配色。
- 项目明确禁止新增长期移动端兼容范围、默认玻璃拟态、营销页式 hero、嵌套背景框和列表行选中填充。

## 方案设计

- 顶部为当前租户和 Semattice 应用状态上下文，强调数据来源和同步时间。
- 主体采用“业务对象目录 + 数据列表”的两段式桌面布局：对象目录固定在列表左侧，列表承载查询、工具栏、表格和分页。
- 对象目录使用无卡片堆叠的轻量导航，选中状态使用文字层级与直线强调。
- 列表顶部提供搜索、视图筛选、刷新、表头设置和主操作入口；表格保持原生 table 语义。
- 行详情以右侧抽屉作为渐进式信息层，保留列表滚动位置；列设置采用不透明轻量浮层。
- 演示数据包含客户、商机、项目三个对象，默认打开客户列表，保证截图初始状态具备真实业务密度。

## 接口与数据影响

- 本阶段无 API、事件、数据库或配置变更。
- 组件将数据结构与展示字段集中在前端演示模块中，后续接入真实元数据/记录查询时可替换数据适配层。

## 任务拆分

- `TASK-266`：实现 AI表格菜单对应的业务对象列表高保真桌面预览、交互状态和验证记录。

## 验收标准

- 点击左侧 AI表格菜单不再渲染 CloudCC 登录 iframe。
- 默认桌面视图展示对象目录、查询区、表格、记录数、分页和同步状态。
- 查询、对象切换、表头设置、刷新反馈、行详情和分页均有可见反馈。
- 生产构建通过，桌面浏览器截图检查通过，关键控件具备清晰 focus/hover/disabled 状态。
- 不新增移动端布局或移动端测试。

## 风险与回滚

- 当前仅为演示数据，真实数据接入前不能作为 API 完成度判断依据。
- 若后续接口字段与演示字段不一致，应保留展示层结构，仅替换记录适配和元数据映射。
- 回滚方式为恢复 CRM 分支原 iframe 渲染，或暂时保留列表预览作为产品占位页。
